# Expense Tracker API

A REST API built with Python and FastAPI to manage personal expenses securely.

## Planned Features

- User registration and login
- JWT-based authentication
- Create, view, update, and delete expenses
- Filter expenses by category and date
- Monthly spending summaries
- Automated tests

## Tech Stack

- Python
- FastAPI
- SQLAlchemy
- Pydantic
- SQLite
- Pytest
